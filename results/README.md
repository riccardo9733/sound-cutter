# Risultati di Elaborazione Video (Results)

Questa cartella è la destinazione predefinita o consigliata per i video esportati da AutoCut:

- `*_clean.mp4`: Il video finale con i suoni indesiderati rimossi.
- `*_events_only.mp4`: Il video riassuntivo contenente esclusivamente gli eventi rilevati (highlights/tagli).
- `*.csv` / `*.txt`: File di diagnostica ed etichette temporali esportate.

> [!NOTE]
> I file video contenuti in questa cartella sono esclusi dal tracciamento Git tramite `.gitignore` per evitare di appesantire il repository.
